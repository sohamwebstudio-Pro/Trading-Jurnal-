# Elite Trader Journal

A modern professional trading journal web app designed for discretionary traders who want to track execution, psychology, liquidity concepts, emotional behavior, and long-term trading growth.

Built with a clean institutional-style dark UI inspired by professional trading dashboards.

---

# Features

## Dashboard
- Total trades
- Win rate
- Average RR
- Profit factor
- Emotional stability score
- Discipline score
- Weekly & monthly tracking

---

## Trade Journal System
Structured discretionary trade review system:

- Market Context
- Liquidity Analysis
- Entry Reason
- Trade Management
- Exit Reason
- Mistakes
- Emotional State
- Trader Growth Insight

---

## Psychology Tracking
Track emotional behavior including:

- Revenge trading
- Fear exits
- Overconfidence

- Discipline consistency
- Emotional stability

- long-term improvement

- overcomplicated indicators
